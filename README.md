# Sahne Takip

Müzisyen için sahne ve ödeme takibi: hangi mekandan ne kadar alındı, ne kadar alacak var, ekibe kime ne kadar gönderildi, bu ay ne kadar kazanıldı.

- Telefon öncelikli web uygulaması (PWA). Android'de Chrome → Uygulamayı yükle.
- Veriler cihazda (IndexedDB) ve bulutta (Supabase, e-posta + şifre ile giriş).
- İstekler ve kararlar: [ROADMAP.md](ROADMAP.md)

```
npm install
npm run dev      # geliştirme
npm test         # testler
npm run build    # yayın derlemesi (dist/)
```
